## 主题配置：销售数据问数

## 被测对象
- 名称：问数智能体（机器人/单聊名「销售数据分析」）
- 类型：飞书自定义智能体（经 MCP 接入 OLAP 数据库）
- 职能描述：销售数据的智能问数。OLAP 中的指标和维度由用户人工设定（非 OLAP 模型真实搭建），本次测试核心目的就是验证问数智能体对这些人工设定的指标/维度的使用是否正确

## 联系通道
- 通道类型：飞书 IM 单聊
- 定位方式：已确认——单聊「销售数据分析」
- chat_id：oc_xxxxxxxxxxxxxxxxxxxxxxxx（用户确认后回填）
- 使用的适配器：adapter-lark-cli.md（Claude Code 宿主 + lark-cli 飞书通道）
- 会话预处理：待 Phase 0 实测后确定（若被测对象反问模型/数据源确认，则补声明话术）

## 元数据探查
探查问题（Phase 1 逐条发送）：
1. 请列出你接入的数据库中所有的指标和维度，要求全部列出，给出精确名称，不要执行任何查询
2. 请补充说明：各维度大致的成员数量，以及哪些指标能按哪些维度拆分、哪些不能
已知事实：
- 指标/维度为人工设定，被测对象的自报清单需用户确认后才作为出题依据
- 数据时间范围：未知，探查时顺带问清（若有真空期，时间类幻觉题出题时注明）

## 角度取舍
- 启用角度：T1-T5 幻觉、E 枚举、P 压力、C 复杂查询、CS 一致性
- 指标全覆盖：不设准确性专门板块，全部用例**合计**每指标 ≥1 条预期返回真实数值的题（角度库横切约束）；各角度轮换取材，出题后按「涉及指标」列核对，缺口补常规查询题
- 条数覆盖：T1-T5 各 3 条；E/P/C 各 3 条（细类轮选）；CS 3 条
- 单题超时：300s

## 出题模式
- 出题人：被测对象自生成——测试方发「出题委托」（角度+条数+格式+难度要求），收回后审核规整、覆盖核对、交叉校验（见角度库「出题执行模式」）

## 用例表
- 表名规则：问数智能体测试用例表_YYYYMMDD（执行日）
- 存放：我的空间（默认位置）

## 边界与禁区
- 回答与 MDX/DAX 语句均由被测对象回复文本自带，原样采集，不做加工
- 判分人工完成，表中判定列只初始化为「待检」
