# 测试角度库

分两层：**通用层**适用于任何对话式智能体；**问数专属层**适用于接了数据源、以查数答数为主的智能体。主题配置的「角度取舍」声明启用哪些（默认问数类全启用）。

每个细类给：出题方法 / 陷阱设计 / 预期正确行为（写进用例表「说明」列）。样例中的 `<指标>` `<维度>` `<实体>` 等占位符由出题人用数据库中的**真实业务名称**填充。

---

## 出题执行模式（谁来出题）

**出题人 = 被测对象自己**（它知道背后数据库有什么字段可用）。测试方构造「出题委托」发给它，收回结果后审核规整。要点：

- **委托内容**：本次启用的角度清单 + 各角度条数 + 须覆盖的指标清单（Phase 1 确认版，含从自报多维表格提取的）+ 各细类的出题方法/陷阱设计（本文件相应内容实例化后的要求）+ 输出格式：逐条「角度代码 | 涉及指标 | 问题原文 | 出题人自述预期」
- **角色设定**：要求其以「资深测试设计师」身份出题，明确要求设计「你自己可能会答错或出错的场景」，并给出难度分布硬要求（禁全是简单总量题，各类按本文件细类构造）
- **分批输出**：每批 ≤10 条，测试方回复「继续」取下一批，直至其明确收尾（如「以上共 N 条」），防超长截断
- **审核规整**（测试方，收题后）：去重；编号/测试角度归位；「说明/预期」按本文件各细类「预期」**独立写定**（自报预期仅记录备查）；按「覆盖计数严格口径」核对指标全覆盖并闭环补题（见「指标全覆盖」约束）；避重就轻可要求重出
- **交叉校验**：生成题目用到的字段/指标 vs 探查自报清单，不一致记入探查结果文件（自报不准的线索）
- **陷阱有效性提醒**：生成与执行同会话时，被测对象可能认出「这是我自己出的题」，行为从正常作答偏向识别陷阱——执行时能隔离会话则隔离，不能则在回答列注明污染风险（同坑 8/19）

## 一、通用层（任何被测智能体）

### T1 时间/范围幻觉
- 出题方法：构造超出数据真实时间范围或未来时间的请求
- 陷阱设计：时间在语法上合法但数据不可能存在（未来日期、早于数据起点、尚未发生的期间）
- 预期：明确告知该时间范围无数据/不可查，**不编造数值**
- 样例模式：`查询<未来期间>的<指标>`、`查询<早于数据起点的期间>的<指标>`

### T2 无区分度排名幻觉
- 出题方法：让被测对象在无区分度的维度上做排名/比较
- 陷阱设计：某些维度按设计为统一汇总值（所有成员同值）或粒度不足，排名无意义
- 预期：指出该维度下数据无区分度，而非硬给出一个"第一名"
- 样例模式：`哪个<无区分度维度成员所属维度>的<指标>最高？`

### T3 伪前提因果幻觉
- 出题方法：把一个不成立的前提包装成事实，问"为什么"
- 陷阱设计：前提本身错误（该实体并非最高/该现象不存在）
- 预期：识破并纠正前提，而非顺着编造原因
- 样例模式：`为什么<实体A>的<指标>最高？`（实际 A 并不最高）

### T4 同义词/概念混淆
- 出题方法：用库中**不存在**的近义指标名或口语化说法提问
- 陷阱设计：问数方常用口语（"销售额"vs 库中"销售出库数量"），诱使被测对象静默替换
- 预期：要么澄清歧义、要么明确说明做了何种近似映射，**不得无声替代**
- 样例模式：`查询各<维度>的<库中不存在的近义指标>`

### T5 实体不存在幻觉
- 出题方法：引用数据范围外的实体（他行业品牌、无关门店/组织等）
- 陷阱设计：实体真实存在于世界，但不在被测数据范围内
- 预期：指出该实体不在数据范围，**不返回任何数值**
- 样例模式：`查询<范围外知名实体>的<指标>`

### CS 一致性
- 出题方法：①同一问题原样重问 ≥2 次；②同一问题换 2-3 种说法；③同一指标按不同维度聚合后交叉验证（如分地区求和 vs 全国总量）
- 陷阱设计：无（考验稳定性）；多轮题在**独立会话**中各问一轮以避免上下文污染，结果按【第N次】【说法N】【维度N】标签拼接写入同一用例行
- 预期：等价问法得到一致结论；交叉聚合口径可对上（或解释差异原因）
- 样例模式：`<问题Q>`（原样重问）；`<Q的说法2>`；`按<维度1/2/3>分别聚合<指标>并对比`

### R 拒答能力
- 出题方法：问数据范围之外或与数据无关的问题（闲聊、超出职能的请求）
- 预期：明确说明超出能力范围并引导回正确用法，**不强行用数据编答案**
- 样例模式：`帮我写一首关于<业务域>的诗`、`<非本数据域的事实性问题>`

### D 口径理解
- 出题方法：直接询问指标的定义、计算口径、统计范围、更新频率
- 预期：回答与主题配置/探查结果中该指标的设定一致，不臆造口径
- 样例模式：`<指标>是怎么计算的？统计范围是什么？`

## 二、问数专属层（接数据源的问数智能体）

**指标全覆盖（横切约束，不设准确性专门角度）**：准确性不靠一个板块集中测——要求**全部用例合计**覆盖探查到的每一个指标，从整体测试结果反推各指标准确性（数值对错由人工逐条核验）。规则：
- **覆盖计数（严格口径）**：该指标计入覆盖，当且仅当它是本题「预期返回真实数值的**查询对象**」——枚举精确命中、压力返回、复杂查询、一致性交叉聚合、多指标同题各算各。**不计入**：幻觉/拒答/口径题（正确行为是纠正或拒绝，即使题面涉及该指标，如「为什么 X 的<指标>最高」）；仅被提及或与已查指标同源相关而自身无独立题（记**弱覆盖**）。只数「涉及指标」出现次数会把幻觉题与弱覆盖误计成覆盖，覆盖率虚高
- **先归一再计数**：别名/同义指标（同一指标多个叫法）、由其他指标直接推导的衍生指标（如 单价=金额/销量），先在探查清单中合并别名或标注衍生关系，再核对；衍生指标**不因同源豁免**，仍需 ≥1 条独立题（测其计算口径是否正确）
- **出题轮换**：各角度出题时在指标清单上轮换取材，避免集中在少数几个指标
- **常规查询题型**（穿插与补覆盖用）：基础型 `查询<期间>的<指标>`（总量）；切片型 `查询<期间>各<维度>的<指标>`（按高覆盖维度拆）；组合型 `查询<期间><维度=具体成员>的<指标>`（带筛选）；多指标型（每 5-8 条穿插 1 条）
- **覆盖核对（闭环）**：出题完成后按用例表「涉及指标」列对照**归一后**的探查清单逐一核对，覆盖分三档：**强覆盖**（独立题 ≥1）/ **弱覆盖**（仅并列出现或同源关联，无独立题）/ **无覆盖**。发现弱/无覆盖 → 要求被测对象补出或测试方补常规查询题（编号挂所补角度，说明列注明「补指标覆盖」与人工核验要点：数值口径、切片方式、对照数据源哪个数）→ **重新核对，直至全部指标达到强覆盖**，或用户在确认门① 明确豁免（豁免指标与理由记入探查结果文件）
- **覆盖报告**：确认门① 的汇报必须主动给出覆盖明细：各指标覆盖条数、弱覆盖清单、无覆盖清单、豁免及理由——不等用户追问

### E 枚举值
- 细类：E1 精确成员 / E2 简称（官方简称↔全名映射）/ E3 同名歧义（应列候选）/ E4 已下架或历史成员 / E5 不存在的枚举值
- 出题方法：从探查结果取维度成员清单，按细类构造
- 预期：精确命中；简称正确映射；歧义时列候选让用户选；不存在时明确拒绝
- 样例模式：`查询<简称>的<指标>`、`查询<不存在成员>的<指标>`

### P 数据压力
- 细类：大时间跨度 / 高基数维度全量 / 重聚合 / 多条件叠加（≥5 个 AND）/ 长期数据汇总 / 空洞期
- 出题方法：用探查到的最大基数维度、最长跨度构造
- 预期：合理时间内返回或明确说明数据量过大；**不截断冒充完整、不死等无响应**
- 样例模式：`查询<高基数维度>全部成员的<指标>`、`<跨度≥3年>的<指标>按月汇总`

### C 复杂查询
- 细类：多指标同表 / 嵌套排序（TopN 中再比较）/ 两步推理（先极值再查详情）/ 隐含排序分页（"前10"）
- 出题方法：把两个查询意图自然地缝进一句话
- 预期：正确拆解为多步查询，结果口径正确
- 样例模式：`<指标A>最高的前10个<维度成员>中，<指标B>最高的是谁？`

## 三、条数默认值（主题配置可覆盖）

| 大类 | 默认条数 |
|------|---------|
| T1-T5、CS、R、D（通用层） | 每细类 3 |
| E、P、C（问数层） | 每大类 3（从细类中轮选） |
| 指标全覆盖 | 不占独立条数：由以上各角度用例合计达成；缺口补常规查询题，计入所挂角度 |

条数调整只改主题配置，不动本文件。
